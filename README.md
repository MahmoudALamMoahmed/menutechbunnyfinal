# 🍽️ منيو تك (MenuBunny) — منصة المنيو الرقمي للمطاعم

منصة SaaS متكاملة تتيح لأي مطعم إنشاء **منيو إلكتروني** خاص به على رابط مستقل، واستقبال **الطلبات** من الزبائن مباشرة عبر لوحة التحكم أو واتساب، مع إدارة كاملة للفروع والأصناف والعروض والاشتراكات.

الواجهة بالكامل **عربية RTL**.

---

## 📌 نظرة سريعة

| العنصر | التفاصيل |
| --- | --- |
| نوع المشروع | تطبيق ويب (SPA) متعدد المستأجرين Multi-tenant |
| رابط المطعم | `/:username` — كل مطعم له اسم مستخدم فريد |
| الواجهة | React 18 + Vite + TypeScript + Tailwind CSS + shadcn/ui |
| الباك اند | Supabase (Postgres + Auth + RLS + Edge Functions) |
| الصور | Bunny CDN (رفع/حذف عبر Edge Functions) |
| المدفوعات | Kashier (محفظة + اشتراكات + تجديد تلقائي) |
| البيانات في الواجهة | TanStack React Query |

---

## 👥 أنواع المستخدمين

| الدور | ما يستطيع فعله |
| --- | --- |
| **الزبون** (بدون تسجيل) | يتصفح منيو المطعم، يختار الحجم/النوع/الإضافات، ويرسل طلبًا عبر لوحة التحكم أو واتساب |
| **صاحب المطعم (Owner)** | إدارة معلومات المطعم، الأصناف والأقسام، الأحجام والأنواع والإضافات، العروض، الفروع ومناطق التوصيل، الفوتر، الطلبات، التقارير، المحفظة والاشتراك |
| **موظف الفرع (Branch Staff)** | يسجّل دخول من صفحة خاصة بالمطعم `/:username/branch-staff-login`، ويرى **طلبات فرعه فقط** (لوحة التحكم + واتساب) |
| **Super Admin** | لوحة إدارة عامة: المطاعم، الاشتراكات، المحافظ، الطلبات |
| **Sales** | متابعة العملاء المحتملين (Leads) |

## ✨ أبرز الميزات

- **منيو رقمي كامل**: أقسام، أصناف، صور، أحجام، أنواع (Variants)، إضافات اختيارية.
- **العروض (Offers)**: شريط عروض مميّز في صفحة المطعم مع ترتيب Drag & Drop من لوحة التحكم.
- **سلة ذكية**: اختيار الحجم/النوع/الإضافات مع حساب فوري للسعر.
- **مسار طلب آمن**: الطلب يُنشأ عبر دالة قاعدة بيانات `create_order` تُعيد حساب كل الأسعار من الجداول، فلا يمكن تزوير الأسعار من المتصفح.
- **قناتان للطلب**: لوحة التحكم (Realtime) أو واتساب برسالة مبنية من بيانات السيرفر.
- **طلبات لحظية** مع تنبيه صوتي عند وصول طلب جديد.
- **فروع ومناطق توصيل** لكل فرع مع أسعار توصيل مستقلة.
- **تقارير**: إجماليات، أفضل الأصناف، أوقات الذروة، أداء الفروع، طرق الدفع.
- **باقات واشتراكات**: حدود لكل باقة + محفظة + تجديد تلقائي عبر Edge Function.
- **رفع صور محسّن**: ضغط في المتصفح + تقطيع (Cropper) + تخزين على Bunny CDN.

## 🔐 الأمان

- **RLS** مُفعّل على الجداول الأساسية، وكل بيانات المطعم مربوطة بـ `owner_id`.
- **الأدوار** مخزّنة في جدول منفصل ويتم التحقق منها عبر دالة `security definer`.
- دور الزائر `anon` **لا يملك أي صلاحية كتابة** على `restaurants` أو `orders`.
- إنشاء الطلبات يمرّ **فقط** عبر دالة `create_order` التي تتحقق من: انتماء الأصناف للمطعم، تفعيل الفرع، صحة منطقة التوصيل، بيانات الزبون، وحدود المعدّل (Rate limit).
- القراءة العامة للمنيو تمرّ عبر view/RPC يعرض **أعمدة مسموحة فقط** (بدون إيميلات أو معرّفات المالك).

## 🚀 التشغيل محليًا

```bash
npm install
npm run dev      # http://localhost:8080
```

أوامر أخرى:

```bash
npm run build    # بناء الإنتاج
npm run lint     # فحص الكود
npm run test     # تشغيل الاختبارات (Vitest)
```

متغيّرات البيئة موجودة في `.env` (مفاتيح Supabase العامة). المفاتيح السرّية (Bunny، Kashier، Service Role) تُخزَّن كـ Secrets في Supabase وتُستخدم داخل Edge Functions فقط.
